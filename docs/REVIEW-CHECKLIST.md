## ⚠️ 你需要做的（只有你能操作微信后台）

### 第一步：下载微信开发者工具
1. 访问 https://developers.weixin.qq.com/minigame/dev/devtools/download.html
2. 下载对应系统版本（macOS / Windows）
3. 安装后扫码登录（用你的微信小游戏开发者账号）

### 第二步：导入项目
1. 打开微信开发者工具
2. 点击「导入项目」（或「+」→「导入」）
3. 目录选择：`wechat-games/词爆星空/src`
4. AppID 会自动读取 `project.config.json`：`wx3bffbc31853d2140`
5. 项目名称：`词爆星空`
6. 点击「导入」

### 第三步：开通云开发（免费额度）
1. 在开发者工具顶部菜单 → 「云开发」
2. 点击「开通」，选择「新建环境」
3. 环境名称：`cibaoxingkong`
4. 选择「免费版」（每月 5GB 存储 + 2万次云函数调用，前期够用）
5. 环境 ID 会生成，记下来告诉我
6. 部署云函数：
   - 右键 `cloudfunctions/login` → 「上传并部署」
   - 右键 `cloudfunctions/userData` → 「上传并部署」
   - 右键 `cloudfunctions/leaderboard` → 「上传并部署」
   - 右键 `cloudfunctions/payment` → 「上传并部署」

### 第四步：开通广告组件（变现关键 🔑）
1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 你的小游戏
2. 左侧菜单 → 「流量主」→ 「开通」
3. 满足条件：累计独立访客(UV) ≥ 1000（新游戏先开通，达标后自动激活）
4. 如果暂时不满足，先提交审核，用户量上来后系统自动开通
5. 开通后创建广告单元：
   - **激励视频广告**：用于复活/领体力/双倍奖励
   - **插屏广告**（可选）：关卡切换时展示
   - 创建后获得广告单元 ID → 告诉我，我注入代码

### 第五步：提交审核
1. 开发者工具右上角 → 「上传」
2. 版本号：`1.0.0`
3. 项目备注：`词爆星空 v1.0 — 国风文字解谜小游戏`
4. 上传成功后，登录 [微信公众平台](https://mp.weixin.qq.com/)
5. 左侧「版本管理」→ 找到刚上传的版本 → 「提交审核」
6. 配置：
   - **类目**：游戏 → 休闲游戏
   - **游戏内容**：文字解谜，成语重组
   - **适龄提示**：无限制（各年龄适用）
   - **隐私协议**：可先用微信默认模板
7. 提交，等待审核（通常 1-7 个工作日）
