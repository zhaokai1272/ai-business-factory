## 2. 下载安装微信开发者工具

### 2.1 下载

打开浏览器，访问微信官方下载页面：

```
https://developers.weixin.qq.com/minigame/dev/devtools/download.html
```

选择对应系统版本：

| 操作系统 | 下载文件 |
|----------|---------|
| **Windows 64位** | `wechat_devtools_1.xx.xx_x64.exe` |
| **macOS (Intel)** | `wechat_devtools_1.xx.xx.dmg` |
| **macOS (Apple Silicon)** | `wechat_devtools_1.xx.xx_arm64.dmg` |

### 2.2 安装

**Windows**:
1. 双击 `.exe` 安装包
2. 默认安装路径即可 → 一路「下一步」→ 完成
3. 桌面会生成「微信开发者工具」快捷方式

**macOS**:
1. 双击 `.dmg` 文件挂载
2. 将「微信开发者工具」拖入 `Applications` 文件夹
3. 首次打开若提示「无法验证开发者」，去「系统设置 → 隐私与安全性 → 仍要打开」

### 2.3 首次启动 & 扫码登录

1. 打开微信开发者工具
2. 用手机微信扫描屏幕二维码
3. 手机上确认登录
4. 工具主界面出现「小程序/小游戏」项目列表（首次为空）

> **提示**：登录后工具会自动记住你的账号，下次打开无需重复扫码。

## 3. 导入项目

> **重要**：3款游戏需分别导入为3个独立项目。每个项目共用同一个 AppID。

### 3.1 项目代码在哪

本项目代码在以下目录，先把整个 `wechat-games` 文件夹复制到你的电脑桌面（通过U盘/网盘/微信文件传输）：

```
/root/ai-factory/wechat-games/
├── 词爆星空/          ← 第1个游戏
│   ├── src/           ← 小游戏代码根目录
│   ├── cloudfunctions/ ← 云函数
│   └── ...
├── 卷王冲冲冲/        ← 第2个游戏
│   ├── src/
│   └── ...
└── 合成亿万达/        ← 第3个游戏
    ├── src/
    └── ...
```

### 3.2 导入步骤（以「词爆星空」为例）

1. 点击工具界面右上角 **「+」** 或 **「导入项目」**
2. 在弹出的「导入项目」对话框中填写：

| 字段 | 填写内容 |
|------|----------|
| **项目名称** | `词爆星空`（自定义，方便识别即可） |
| **目录** | 点击「选择」→ 找到 `wechat-games/词爆星空/src/` 文件夹 |
| **AppID** | 输入 `wx3bffbc31853d2140` |
| **开发模式** | 选择「小游戏」 |
| **后端服务** | 选择「微信云开发」（后续开通） |

3. 点击「导入」→ 等待项目加载完成

### 3.3 重复导入其余2款游戏

按同样步骤，分别导入：

| 项目名称 | 源码目录 | AppID |
|----------|---------|-------|
| 卷王冲冲冲 | `wechat-games/卷王冲冲冲/src/` | `wx3bffbc31853d2140` |
| 合成亿万达 | `wechat-games/合成亿万达/src/` | `wx3bffbc31853d2140` |

### 3.4 验证导入成功

- 双击项目名称，进入编辑器界面
- 左侧文件树应能看到 `game.js`、`game.json`、`project.config.json` 等文件

> **首次编译可能较慢**（30秒–1分钟），这是正常现象。后续编译会变快。

## 4. 开通云开发

微信云开发提供免费额度，个人开发者足够使用。

### 4.1 开通步骤

1. 在微信开发者工具中，点击顶部菜单栏 **「云开发」** 按钮（云朵图标）
2. 首次使用会弹出「开通云开发」面板：

| 字段 | 填写内容 |
|------|---------|
| **环境名称** | `ai-factory-prod`（或任意英文名） |
| **环境ID** | 系统自动生成（如 `ai-factory-prod-xxxxx`） |
| **付费方式** | 选择 **「预付费」** → **「免费版」**（个人开发者选免费） |

3. 点击「确定」→ 等待环境创建（约 10–30 秒）

### 4.2 免费额度一览

| 资源 | 免费额度 | 说明 |
|------|---------|------|
| 云数据库存储 | 2 GB | 文本数据绰绰有余 |
| 云数据库读操作 | 5万次/天 | 日活500以内完全免费 |
| 云数据库写操作 | 3万次/天 | 同上 |
| 云函数调用 | 20万次/月 | 小游戏初期够用 |
| 云函数资源 | 4万GBs/月 | 内存256MB默认 |
| 云存储 | 5 GB | 图片/音频资源 |
| CDN流量 | 5 GB/月 | 资源下载流量 |

> **对于个人小游戏日活 < 500，以上全部免费**。如果爆量，再考虑升级配额。

### 4.3 记录环境ID

开通成功后，记下环境ID（非常重要，后续步骤需要）：

```
你的环境ID: ___________________
（格式类似: cloud1-xxxxxxxxx）
```

在云开发控制台左侧底部可看到。

## 5. 创建数据库集合

在云开发控制台 → **「数据库」** 标签页，创建以下5个集合。

### 5.1 操作步骤

1. 点击 **「添加集合」**
2. 输入集合名称 → 确定
3. **每个集合都要设置权限**

### 5.2 集合清单

| # | 集合名称 | 用途 | 权限设置 |
|---|---------|------|---------|
| 1 | `users` | 用户数据（金币/钻石/体力） | **仅创建者可读写** |
| 2 | `leaderboard` | 排行榜 | **所有用户可读，仅创建者可写** |
| 3 | `purchases` | 支付记录 | **仅创建者可读** |
| 4 | `gameRecords` | 游戏记录 | **仅创建者可读写** |
| 5 | `adRecords` | 广告观看记录 | **仅创建者可写** |

### 5.3 设置权限（以 `users` 为例）

1. 点击集合名称进入
2. 点击 **「权限设置」** 标签
3. 选择 **「仅创建者可读写」**
4. 点击保存

### 5.4 创建索引（提升排行榜查询速度）

`leaderboard` 集合需要创建索引：

1. 点击 `leaderboard` 集合
2. 点击 **「索引管理」** → **「添加索引」**
3. 添加以下两个字段的联合索引：

| 字段 | 排序 |
|------|------|
| `gameName` | 升序 |
| `score` | 降序 |

4. 保存

## 6. 部署云函数

> **注意**：目前云函数代码仅存在于「词爆星空」项目中。3款游戏共用同一套云函数和同一环境。

### 6.1 确认云函数目录

在「词爆星空」项目的文件树中，应能看到 `cloudfunctions/` 目录，内含4个云函数：

```
cloudfunctions/
├── login/          ← 用户登录 & 初始化
│   └── index.js
├── leaderboard/    ← 排行榜管理
│   └── index.js
├── userData/       ← 用户数据读写
│   └── index.js
└── payment/        ← 支付处理
    └── index.js
```

### 6.2 部署步骤

1. 在开发者工具左侧文件树中，**右键点击 `cloudfunctions/` 目录**
2. 选择 **「当前环境」** → 确认选中你刚创建的环境（如 `ai-factory-prod`）
3. 右键点击第一个云函数文件夹（如 `login`）
4. 选择 **「上传并部署：云端安装依赖」**
5. 等待上传完成（控制台底部会显示进度）
6. 对剩余3个云函数（`leaderboard`、`userData`、`payment`）重复步骤 3–5

### 6.3 验证部署

1. 进入云开发控制台 → **「云函数」** 标签
2. 应看到4个云函数，状态为 **「部署成功」** 绿色标识
3. 点击某个云函数 → 可看到基本信息（内存/超时等）

### 6.4 云函数默认配置（不需要修改）

| 参数 | 值 |
|------|-----|
| 内存 | 256 MB |
| 超时时间 | 3 秒 |
| 环境 | 自动注入 |

## 7. 修改环境ID配置

云开发环境创建后，需要在代码中将占位符替换为实际环境ID。

### 7.1 找到需要修改的文件

打开 `game.js`（项目根目录下的主入口文件），找到云开发初始化代码块：

```javascript
// 位于 game.js ~第23行
wx.cloud.init({
  env: 'production-xxxx', // ← 这里需要修改
  traceUser: true
});
```

### 7.2 替换为实际环境ID

将 `'production-xxxx'` 替换为你的实际环境ID，例如：

```javascript
wx.cloud.init({
  env: 'ai-factory-prod-7gxxx',  // ← 改为你的实际环境ID
  traceUser: true
});
```

### 7.3 对所有3款游戏执行此操作

| 游戏 | 修改文件 |
|------|---------|
| 词爆星空 | `game.js` |
| 卷王冲冲冲 | `game.js` |
| 合成亿万达 | `game.js` |

> 3款游戏的 `game.js` 都需要修改，都改为同一个环境ID。

## 8. 本地真机调试

在上传审核之前，强烈建议在真机上测试一遍。

### 8.1 操作步骤

1. 点击工具栏 **「预览」** 按钮
2. 工具会生成一个二维码
3. 用手机微信扫描二维码
4. 手机上会打开小游戏

### 8.2 检查清单

| # | 检查项 | 正常表现 |
|---|--------|---------|
| 1 | 游戏能正常启动 | 看到菜单界面 |
| 2 | 云函数调用成功 | 控制台无报错（可在 vConsole 查看） |
| 3 | 场景切换正常 | 从菜单→游戏→结算流畅 |
| 4 | 基础操作响应 | 点击/拖拽/滑动有反应 |
| 5 | 无闪退/白屏 | 运行超过30秒无异常 |

### 8.3 开启 vConsole 调试

- 预览时勾选 **「开启调试」** 选项
- 手机扫码后，右下角会出现绿色 vConsole 按钮
- 点击可查看 console.log 输出和网络请求

### 8.4 常见真机问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 白屏 | 缺少资源文件 | 检查图片路径是否正确引用 |
| 云函数报错 | 未正确设置环境ID | 返回步骤7检查 |
| 广告不显示 | 未开通广告/ID为占位符 | 见步骤11 |
| 闪退 | 内存溢出 | 检查资源加载，降低图片分辨率 |

## 10. 提交审核

### 10.1 进入 MP 后台

1. 打开浏览器，访问微信公众平台：
   ```
   https://mp.weixin.qq.com/
   ```
2. 用管理员微信扫码登录
3. 在左侧菜单找到 **「开发管理」** → 上方标签切换到 **「小游戏」**
4. 或直接访问小游戏管理后台：
   ```
   https://mp.weixin.qq.com/wxagame/
   ```

### 10.2 配置小游戏基本信息

首次提交审核前，必须先填写小游戏基本信息（在 **「设置」** → **「基本设置」**）：

| 配置项 | 要求 | 示例 |
|--------|------|------|
| **游戏名称** | 2–10个汉字，不能与已有游戏重名 | `词爆星空` |
| **游戏图标** | 144×144 px，PNG格式，< 200KB | 游戏Logo |
| **游戏简介** | 20–200字，说明玩法 | 见下方模板 |
| **游戏类目** | 选择最匹配的类目 | 见下方说明 |
| **服务范围** | 游戏服务 | 默认全选 |

#### 游戏简介模板

```

国风文字解谜游戏。在4×4字卡网格中，找出隐藏的成语或四字词。
限时60秒挑战，连击爆分，支持全国排行榜。
```

#### 游戏类目选择

| 游戏 | 推荐一级类目 | 推荐二级类目 |
|------|------------|------------|
| 词爆星空 | 休闲 | 益智 |
| 卷王冲冲冲 | 休闲 | 跑酷 |
| 合成亿万达 | 休闲 | 放置 |

> **个人开发者限制**: 不能选择「棋牌」「竞猜」「捕鱼」等类目。休闲类目个人开发者无限制。

### 10.3 配置游戏内容（审核关键）

在 MP 后台 → **「开发管理」** → **「开发版本」** 中：

1. 找到你刚上传的版本（版本号 `1.0.0`）
2. 点击右侧 **「提交审核」**
3. 填写审核表单：

#### 审核表单详解

| 字段 | 说明 | 填写建议 |
|------|------|---------|
| **配置功能页面** | 展示游戏核心页面截图 | 上传3-5张游戏内截图 |
| **服务类目** | 需与基本设置一致 | 休闲/益智等 |
| **游戏内容介绍** | 描述游戏玩法、功能 | **详细写！审核员会逐字看** |
| **测试账号** | 若游戏需登录 | 个人小游戏一般无需 |
| **技术说明** | 有特殊权限需说明 | 本项目仅使用云开发和广告，无需特殊说明 |

### 10.4 审核时间

| 类型 | 预计时间 |
|------|---------|
| 首次提审 | 1–7 个工作日（通常 3 天内） |
| 版本更新 | 1–3 个工作日 |
| 加急审核 | 每个季度有 2 次加急机会（1小时内出结果） |

### 10.5 审核通过后

1. 微信会通过「公众平台安全助手」公众号推送审核结果
2. 通过后，在 MP 后台 → **「开发管理」** → 点击 **「发布上线」**
3. 发布后约 5–30 分钟，用户可通过搜索/扫码进入小游戏

## 11. 开通广告组件

> **前提**: 小游戏通过审核并发布上线后，才可开通广告组件。未上线前只能在开发版/体验版中测试。

### 11.1 开通流量主

1. 登录 MP 后台 → **「流量主」**（左侧菜单）
2. 点击 **「开通」**
3. 条件要求（个人小游戏）：
   - 累计独立访客（UV）≥ 1000（系统自动统计）
   - 无违规记录
4. 达到条件后，填写财务信息（身份证+银行卡号，用于收益结算）

### 11.2 创建广告位

流量主开通后，在「流量主」→「广告管理」中：

1. 点击 **「新建广告位」**
2. 选择广告类型：**「激励视频广告」**（本项目主要收入来源）
3. 填写广告位名称（如 `复活广告`、`道具获取广告`）
4. 系统生成 **广告位ID**（adUnitId），格式如 `adunit-xxxxxxxxxxxxx`

### 11.3 替换广告位ID

拿到真实广告位ID后，回到项目代码，修改 `js/utils/AdManager.js`：

```javascript
// 修改前（占位符）
this.adUnitIds = {
  revive: 'adunit-xxxxxxxxxxxxx',
  hint: 'adunit-xxxxxxxxxxxxx',
  // ...
};

// 修改后（真实ID）
this.adUnitIds = {
  revive: 'adunit-a1b2c3d4e5f6g7h8',   // ← 实际ID
  hint: 'adunit-i9j0k1l2m3n4o5p6',      // ← 实际ID
  double: 'adunit-xxxxx',
  energy: 'adunit-xxxxx',
  signin: 'adunit-xxxxx',
  accelerate: 'adunit-xxxxx'
};
```

> **建议**: 为不同场景创建不同广告位（复活/道具/签到），方便分别统计收入。

### 11.4 广告收益说明

| 广告类型 | 预估收益 | 备注 |
|----------|---------|------|
| 激励视频 | ¥15–50 / 千次观看 (eCPM) | 核心收入来源 |
| Banner | ¥1–5 / 千次展示 | 不太适合小游戏 |
| 插屏 | ¥5–15 / 千次展示 | 可用在关卡间隙 |

## 12. 审核被拒后如何处理

### 12.1 常见拒绝原因 & 解决方案

| 拒绝原因 | 触发条件 | 解决方案 |
|----------|---------|---------|
| **类目不符** | 选了不可用类目 | 改为「休闲」类目重新提交 |
| **功能不完整** | 游戏有明显未完成功能/闪退 | 修复bug，确保核心循环完整 |
| **缺乏用户授权** | 获取用户信息未弹窗 | 添加 `wx.getUserInfo` 授权弹窗 |
| **缺少隐私政策** | 页面无隐私协议入口 | 在设置页添加「隐私政策」链接 |
| **含违规内容** | 涉政/涉黄/敏感词 | 排查所有文本，移除敏感内容 |
| **测试账号失败** | 审核员无法体验游戏 | 提供测试账号或确保免登录体验 |
| **小程序/小游戏混淆** | 配置为非小游戏类型 | 确保 `project.config.json` 中 `compileType` 为 `"game"` |
| **名称侵权** | 名称含他人商标 | 修改游戏名称 |
| **界面过于简陋** | 审核员觉得质量太低 | 至少补充一套完整美术资源后再提交 |

### 12.2 重新提审流程

1. 在 MP 后台 **「开发管理」** → 查看「审核不通过」的具体原因
2. 根据拒绝原因修改代码
3. 在开发者工具中 **重新上传**（版本号递增，如 `1.0.1`）
4. 重新提交审核，在备注中说明 **「已修复：XXX问题」**
5. 如果有加急次数，可勾选「使用加急审核」加速

### 12.3 审核沟通技巧

- **备注要详细**：在提交审核的备注栏，把修复了什么写清楚。审核员会看备注。
- **截图要全面**：上传的截图覆盖所有核心页面（菜单、玩法、结算、设置）。
- **测试说明要具体**：如果游戏有特殊机制，在「技术说明」中简要描述玩法流程。
- **避免多次重复提交**：同一问题被拒3次以上，账号可能被降权。

## 13. 3款游戏上线顺序建议

建议按以下顺序提交，降低审核风险：

```
第1天: 词爆星空 → 最先提交（云函数最完整）
第3天: 卷王冲冲冲 → 词爆星空通过后提交
第5天: 合成亿万达 → 跑通流程后提交
```

这样做的原因：
1. **词爆星空**云函数代码最完整，先跑通整个流程
2. 第1个游戏踩的坑，后续2款不会再犯
3. 避免3个同时被拒，影响开发者信用分

## 14. 常见问题 FAQ

### Q1: 个人开发者能同时发布3款小游戏吗？
**A**: 可以。同一个微信号可以作为多个小游戏的管理员。但一个 AppID 对应一款游戏。目前3款游戏共用一个 AppID，如需分开管理，需在 MP 后台先后更名上线（不推荐），或申请额外 AppID（每个微信号可申请多个）。

> **更好的做法**：3款游戏作为一个「游戏盒子」提交，在首页做游戏选择菜单，这样只需提交1次审核，用户体验也更统一。

### Q2: 云开发免费额度用完了怎么办？
**A**: 不会用完。除非日活超过1000且频繁读写数据库。如果确实不够：
1. 进入云开发控制台 → 「设置」 → 「配额调整」
2. 升级到「基础版」（约 ¥20/月）或按量付费

### Q3: 预览和真机看到的不一样？
**A**: 正常。模拟器是基于 Chrome 内核的桌面模拟，与手机微信环境有差异。最终以真机扫码预览为准。

### Q4: 可以跳过云开发，用自己服务器吗？
**A**: 可以，但不推荐。云开发免运维、自带CDN、自动扩容。个人服务器需自己处理备案/HTTPS/扩容，性价比低。

### Q5: 审核需要多久？
**A**: 通常 1–3 个工作日。节假日可能延迟。首次审核一般比后续更严。

### Q6: 审核通过后怎么更新版本？
**A**:
1. 修改代码 → 在开发者工具中上传（新版本号）
2. MP后台 → 开发管理 → 提交审核
3. 审核通过 → 发布上线（用户会自动更新）

### Q7: game.json 中的 deviceOrientation 填什么？
**A**:
- 词爆星空、合成亿万达：`"portrait"`（竖屏）
- 卷王冲冲冲：`"portrait"`（竖屏，跑酷游戏竖屏更适合单手操作）

### Q8: 是否需要保留 console.log？
**A**: 正式上线前建议删除或注释掉所有 `console.log`，减少性能开销，也避免敏感信息泄露。
