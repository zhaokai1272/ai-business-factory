## 1. 核心概念

### 1.1 一句话描述

> 操控"打工人"在办公室赛道中横向跑酷，躲老板、溜会议、反加班、避裁员，咖啡续命、摸鱼攒分、涨薪逆袭——卷得越久，活得越久！

### 1.2 目标用户画像

| 维度 | 描述 |
|------|------|
| **年龄** | 18–35 岁 |
| **身份** | 职场白领、应届生、实习生、自由职业者 |
| **场景** | 通勤碎片时间、午休、排队、等电梯 |
| **动机** | 释放职场压力、寻找共鸣梗、轻度竞技炫耀 |
| **文化标签** | "打工人""内卷""躺平""摸鱼""00后整顿职场" |
| **付费习惯** | 小额冲动消费 (1–6元皮肤)、广告容忍度高 |

### 1.3 核心游戏循环 (30秒闭环)

```
┌──────────────────────────────────────────────────────┐
│                   30 秒 核 心 循 环                    │
├──────────────────────────────────────────────────────┤
│                                                      │
│   START ──→ 跑酷躲避 ──→ 被击中/体力耗尽 ──→ 结算     │
│     ↑           │                          │        │
│     │    收集咖啡☕续命                      ↓        │
│     │    收集摸鱼🐟加分               看广告复活?      │
│     │    收集涨薪💰金币              ├── 是 → 继续    │
│     │                                └── 否 → 结束    │
│     └──── 消耗金币买皮肤/道具 ←──── 获得金币+分数     │
│                                                      │
└──────────────────────────────────────────────────────┘
```

- **30秒内完成**: 一轮跑酷（新手约30秒死亡，高手可达数分钟）
- **获得**: 分数（排行榜炫耀）+ 金币（经济货币）
- **消费**: 金币买皮肤/道具 → 差异化外观 → 分享动力

## 2. 玩法机制

### 2.1 操作方式

游戏采用 **3 跑道 + 单点/长按** 极简操作：

| 操作 | 手势 | 效果 |
|------|------|------|
| **上滑** | 手指向上滑动 | 角色跳起（跨越低障碍） |
| **下滑** | 手指向下滑动 | 角色滑铲（钻过低障碍/摸鱼） |
| **左滑** | 手指向左滑动 | 切换到左侧跑道 |
| **右滑** | 手指向右滑动 | 切换到右侧跑道 |
| **长按** | 按住屏幕 ≥0.3s | 角色「装忙」减速 + 短暂无敌帧 (0.5s) |

> **设计原则**: 30秒内理解全部操作。首次进入强制 3 步引导（滑一次 + 跳一次 + 换道一次）。

### 2.2 核心规则（3条）

1. **躲开一切红色障碍**：老板突袭、会议通知、加班通知、裁员信命中即扣1条命（共3条命，或随时间递减的体力条）。
2. **吃光一切绿色道具**：咖啡续命、摸鱼加分、涨薪加金币，连吃同类道具触发 combo 加成。
3. **越跑越快，越久越卷**：游戏速度随存活时间线性+阶梯式递增，压迫感持续升温。

### 2.3 胜负判定

| 条件 | 结果 |
|------|------|
| **生命值归零** (3条命耗尽) | 游戏结束 → 结算界面 |
| **体力值归零** (体力条耗尽, 约120s) | 游戏结束 → 结算界面 |
| **触发现「躺平」道具** | 主动结束 → 结算时金币 ×1.5 |

> 体力系统保证单局上限约 120 秒，控制广告曝光节奏。

### 2.4 得分系统

```
总分 = 基础分 + 道具分 + Combo加成 + 距离奖励
     = 跑动距离 × 速度系数
     + Σ(道具基础分 × Combo倍率)
     + ⌊存活秒数⌋ × 时间奖励系数
```

详细公式见 [4.1 得分公式](#41-得分公式)。

## 3. 关卡/节奏设计

### 3.1 难度曲线

游戏不使用传统"关卡"，而是**无限跑酷 + 难度递增**：

```
速度 V(t) = V₀ + α·t + β·⌊t/T_step⌋

其中:
  V₀     = 基础速度  = 300 px/s
  α      = 线性增速  = 0.8 px/s²
  β      = 阶梯跳跃  = 40 px/s
  T_step = 阶梯间隔  = 15 s
  V_max  = 上限速度  = 900 px/s
```

| 时间区间 | 速度范围 (px/s) | 障碍密度 | 体感 |
|----------|----------------|----------|------|
| 0–15s    | 300–312       | 低 (1个/2s) | 😊 轻松 |
| 15–30s   | 352–364       | 中 (1个/1.5s) | 😐 还行 |
| 30–60s   | 404–500       | 中高 (1个/1s) | 😰 开始卷 |
| 60–90s   | 540–620       | 高 (1.5个/s) | 🔥 996模式 |
| 90–120s  | 660–900       | 极高 (2个/s) | 💀 猝死边缘 |

**难度参数表**：

| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 基础速度 | V₀ | 300 | 单位: px/s |
| 线性加速度 | α | 0.8 | 单位: px/s² |
| 阶梯增量 | β | 40 | 单位: px/s |
| 阶梯周期 | T_step | 15 | 单位: s |
| 最大速度 | V_max | 900 | 单位: px/s |
| 初始障碍间隔 | D₀ | 500 | 单位: px |
| 最小障碍间隔 | D_min | 200 | 单位: px |
| 障碍密度最大 | ρ_max | 2.0 | 单位: 个/s |
| 道具出现率 | P_item | 0.15 | 概率/每次生成机会 |

### 3.2 关卡生成算法 (伪代码)

```python
# 障碍/道具生成器 — 无限跑酷核心
class LevelGenerator:
    def __init__(self):
        self.elapsed = 0          # 游戏已进行秒数
        self.speed = V0           # 当前速度
        self.next_spawn_x = 800   # 下一个生成点 (屏幕右侧外)
        self.lane_width = 120     # 跑道宽度

    def update(self, dt: float):
        self.elapsed += dt
        self.speed = min(V_MAX, V0 + ALPHA * self.elapsed 
                         + BETA * floor(self.elapsed / T_STEP))
        self.next_spawn_x -= self.speed * dt

    def should_spawn(self) -> bool:
        if self.next_spawn_x <= SCREEN_RIGHT:
            return True
        return False

    def spawn(self) -> SpawnEvent:
        # 1. 根据当前速度决定障碍密度
        density = lerp(0.5, 2.0, self.speed / V_MAX)
        
        # 2. 决定生成类型: 80%障碍, 20%道具
        if random() < 0.80:
            return self.spawn_obstacle(density)
        else:
            return self.spawn_item()

    def spawn_obstacle(self, density: float) -> Obstacle:
        # 随机选择障碍类型 (权重表)
        pool = weighted_choice([
            ("boss_patrol",     0.20),   # 老板巡逻
            ("meeting_notice",  0.25),   # 会议通知
            ("overtime_alarm",  0.20),   # 加班警报
            ("layoff_letter",   0.10),   # 裁员信 (难)
            ("pua_bubble",      0.15),   # PUA话术气泡
            ("urgent_deadline", 0.10),   # 紧急DDL (极难)
        ])
        
        # 随机分配跑道 (0/1/2)
        lane = random.randint(0, 2)
        
        # 同一跑道不连续生成 >2个障碍
        if self.last_lane == lane and self.same_lane_count >= 2:
            lane = (lane + 1) % 3
        
        # 高密度时可能跨跑道
        if density > 1.5 and random() < 0.3:
            # 生成跨2跑道的大障碍
            return Obstacle(type=pool, lanes=[lane, (lane+1)%3])
        
        return Obstacle(type=pool, lanes=[lane])

    def spawn_item(self) -> Item:
        pool = weighted_choice([
            ("coffee",     0.30),   # ☕ 咖啡: 续命+1
            ("moyu_fish",  0.25),   # 🐟 摸鱼: +combo分
            ("raise_bag",  0.20),   # 💰 涨薪: +金币
            ("tangping",   0.10),   # 🛏️ 躺平: 主动结束×1.5金币
            ("shield_bag", 0.10),   # 🛡️ 护身符: 挡1次伤害
            ("speed_boost",0.05),   # ⚡ 冲刺鞋: 2秒无敌+磁吸
        ])
        
        lane = random.randint(0, 2)
        return Item(type=pool, lane=lane)

    def calculate_next_spawn_distance(self) -> float:
        # 间距 = 基础间距 / 密度, 添加 ±20% 随机
        base = D0 / self.get_density()
        return base * random.uniform(0.8, 1.2)
```

## 4. 数值系统

### 4.1 得分公式

```
Score = DistanceScore + ItemScore + ComboBonus + TimeBonus

DistanceScore = ⌊distance / 10⌋ × SpeedMultiplier
  SpeedMultiplier = 1 + (V_current - V0) / V0 × 0.5
  即: 速度越快, 每单位距离得分越高

ItemScore = Σ item_base_score[i] × combo_multiplier
  combo_multiplier = 1 + min(combo_count - 1, 9) × 0.5
  即: 连吃同类道具, 最高 ×5.5

TimeBonus = ⌊elapsed_seconds⌋ × 10
  即: 每秒存活+10分
```

**道具基础分**：

| 道具 | base_score | 说明 |
|------|-----------|------|
| ☕ 咖啡 | 50 | 续命+1 |
| 🐟 摸鱼 | 100 | combo核心 |

### 4.2 经济系统

游戏使用 **双重货币**：

| 货币 | 获取途径 | 用途 |
|------|----------|------|
| 🪙 **金币** (软货币) | 游戏收集、每日签到、看广告 | 购买皮肤、消耗道具 |
| 💎 **钻石** (硬货币) | 内购、看广告(少量)、成就奖励 | 购买稀有皮肤、跳过广告券 |

**汇率**：

```
1 钻石 ≈ 100 金币 (单向兑换)
1 元人民币 ≈ 10 钻石
```

**体力系统**：

```
体力上限 = 5 颗心
恢复速度 = 1颗心 / 10分钟 (全部恢复需50分钟)
看广告    = 恢复1颗心 (每日上限3次)
钻石购买  = 5钻石恢复1颗心 (无上限)
好友赠送  = 每日最多接收3颗心
```

## 8. 技术需求

### 8.1 数据表结构

#### 表 1: `players` (玩家主表)

```sql
CREATE TABLE players (
    id              VARCHAR(64)  PRIMARY KEY,    -- openid
    nickname        VARCHAR(128) NOT NULL,        -- 微信昵称
    avatar_url      VARCHAR(512),                 -- 微信头像
    coins           INT DEFAULT 0,                -- 金币
    diamonds        INT DEFAULT 0,                -- 钻石
    stamina         INT DEFAULT 5,                -- 当前体力
    stamina_max     INT DEFAULT 5,                -- 体力上限
    stamina_last_recover TIMESTAMP,               -- 上次体力恢复时间
    high_score      INT DEFAULT 0,                -- 最高分
    total_plays     INT DEFAULT 0,                -- 总局数
    total_fish      INT DEFAULT 0,                -- 累计摸鱼次数
    current_skin    VARCHAR(32) DEFAULT 'skin_01',-- 当前皮肤
    rank_tier       INT DEFAULT 0,                -- 段位 0-9
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);
```

#### 表 2: `player_skins` (玩家皮肤)

```sql
CREATE TABLE player_skins (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    player_id       VARCHAR(64) NOT NULL,
    skin_id         VARCHAR(32) NOT NULL,
    acquired_at     TIMESTAMP DEFAULT NOW(),
    UNIQUE KEY uk_player_skin (player_id, skin_id)
);
```

#### 表 3: `player_items` (玩家道具背包)

```sql
CREATE TABLE player_items (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    player_id       VARCHAR(64) NOT NULL,
    item_id         VARCHAR(32) NOT NULL,
    quantity        INT DEFAULT 1,
    level           INT DEFAULT 1,
    UNIQUE KEY uk_player_item (player_id, item_id)
);
```

#### 表 4: `game_records` (游戏记录)

```sql
CREATE TABLE game_records (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    player_id       VARCHAR(64) NOT NULL,
    score           INT NOT NULL,
    distance        INT,                  -- 米
    duration        INT,                  -- 秒
    fish_count      INT DEFAULT 0,        -- 摸鱼次数
    death_cause     VARCHAR(32),          -- 死因
    coins_earned    INT DEFAULT 0,
    skin_used       VARCHAR(32),
    created_at      TIMESTAMP DEFAULT NOW(),
    INDEX idx_player_score (player_id, score DESC),
    INDEX idx_created (created_at)
);
```

#### 表 5: `ad_watch_logs` (广告观看日志)

```sql
CREATE TABLE ad_watch_logs (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    player_id       VARCHAR(64) NOT NULL,
    ad_type         VARCHAR(32) NOT NULL,  -- revive/double/signin/stamina/item
    reward_given    BOOLEAN DEFAULT FALSE,
    watched_at      TIMESTAMP DEFAULT NOW(),
    INDEX idx_player_date (player_id, watched_at)
);
```

#### 表 6: `iap_orders` (内购订单)

```sql
CREATE TABLE iap_orders (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    player_id       VARCHAR(64) NOT NULL,
    product_id      VARCHAR(64) NOT NULL,
    amount          INT NOT NULL,           -- 分 (人民币)
    transaction_id  VARCHAR(128),           -- 微信支付订单号
    status          VARCHAR(16) DEFAULT 'pending', -- pending/success/failed
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);
```

#### 表 7: `daily_signin` (每日签到)

```sql
CREATE TABLE daily_signin (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    player_id       VARCHAR(64) NOT NULL,
    day_index       INT NOT NULL,            -- 签到周期第几天 1-7
    reward_coins    INT DEFAULT 0,
    ad_multiplied   BOOLEAN DEFAULT FALSE,   -- 是否看广告翻倍
    signed_at       DATE NOT NULL,
    UNIQUE KEY uk_player_date (player_id, signed_at)
);
```
