## 1. 核心概念

### 1.1 一句话描述
**词爆星空**是一款将乱序汉字卡片拖拽组词、限时找词的国风文字解谜游戏——四字成语、网络热词、谐音梗，认出即爆。

### 1.2 目标用户画像

| 维度 | 描述 |
|------|------|
| 年龄段 | 12-40岁中文母语用户 |
| 兴趣标签 | 成语接龙、填字游戏、脑筋急转弯、国风文化、网络梗 |
| 使用场景 | 通勤碎片时间（3-10分钟）、睡前放松、排队等候 |
| 付费意愿 | 轻度付费（看广告为主），月均ARPU 3-8元 |
| 性别 | 女性略多（55:45），文字游戏天然偏女性向 |

### 1.3 核心循环

```
┌──────────────────────────────────────────────────────┐
│              30秒核心循环                              │
│                                                       │
│  看到乱序字卡  ──▶  拖拽组词  ──▶  命中引爆特效       │
│       ↑                              │                │
│       │                              ▼                │
│  新一局开始  ◀──  结算奖励  ◀──  计时结束/全部找出    │
│                                                       │
│  获得: 金币 + 星尘(经验)                               │
│  消费: 1点体力/局                                     │
└──────────────────────────────────────────────────────┘
```

**一句话概述**: 30秒内，从16-25张乱序汉字卡片中找出隐藏的4个目标词，点击/拖拽选中，命中即爆——获得金币与星尘，消耗1体力。

## 2. 玩法机制

### 2.1 操作方式

| 操作 | 触发方式 | 反馈 |
|------|----------|------|
| **点选单字** | 点击1张卡片 | 卡片高亮悬浮，底栏候选区显示 |
| **连选组词** | 依次点击4张卡片（无顺序要求） | 卡片依次飞入底栏拼成词语预览 |
| **撤销回退** | 点击已选卡片 或 点击底栏单字 | 卡片退回原位 |
| **提交确认** | 双击最后一张卡片 或 点击底栏「✓」 | 进入判定 |
| **提示** | 点击「💡提示」按钮 | 消耗道具/看广告，高亮1个未命中字的正确位置 |

### 2.2 核心规则

1. **乱序重组**: 每局从词库随机抽取4个目标词，打散为16个单字卡片（4词×4字），随机散布在5×5网格中（含9个干扰空位或干扰字）。
2. **任意顺序**: 用户可按任意顺序选中4个字组成一个词，不要求按词内顺序排列——只要集合正确即判定命中。
3. **限时压力**: 每局默认60秒倒计时，超时未找出全部4词则结算当前进度。

### 2.3 胜负判定

- **胜利**: 60秒内找出全部4个目标词 → 触发「词爆星空」全屏特效 + 完美奖励
- **半胜**: 找出2-3个词后超时 → 按已找出数量结算，无完美奖励
- **失败**: 找出0-1个词后超时 → 保底安慰奖，鼓励「再来一局」

### 2.4 得分系统

每局得分由三部分构成：

```
总分 = 命中分 + 速度分 + 连击分

命中分 = 每个词500分 × 命中词数
速度分 = max(0, (剩余秒数 / 总秒数) × 1000)   // 提前完成奖励
连击分 = 连续命中次数 × 200                     // 第1词0、第2词200、第3词400、第4词600
```

**示例**: 60秒内30秒找出全部4词 → 2000 + 500 + 600 = 3100分

## 3. 关卡/节奏设计

### 3.1 难度曲线

难度由5个维度综合控制：

| 参数 | 符号 | 说明 |
|------|------|------|
| 目标词数 | N | 3-6个（默认4） |
| 干扰字数 | D | 0-9个无关字 |
| 网格大小 | G | 4×4 到 6×6 |
| 限时时长 | T | 30-120秒 |
| 词库难度 | L | 1-5级（常见词→生僻词） |

**难度等级公式**:

```
难度分 = floor(N/2) + floor(D/3) + floor((G-4)×2) + floor((120-T)/30) + L

难度分 0-3  → 简单（新手前10局）
难度分 4-6  → 普通（10-50局）
难度分 7-9  → 困难（50-200局）
难度分 10+  → 地狱（200局后，成就党专属）
```

### 3.2 关卡生成算法（伪代码）

```
function generateLevel(userLevel):
    // 1. 根据用户等级确定参数
    config = difficultyCurve(userLevel)
    N = config.targetWords       // 4
    D = config.distractorChars   // 3
    G = config.gridSize          // 5
    
    // 2. 从词库按主题/难度采样
    wordPool = filterWordPool(minDifficulty=userLevel-2, maxDifficulty=userLevel+2)
    targetWords = weightedRandomSample(wordPool, N)
    
    // 3. 避免冲突检测
    while hasOverlappingChars(targetWords):
        targetWords = weightedRandomSample(wordPool, N)
    
    // 4. 收集所有字符
    allChars = flatten(targetWords)  // 4×4=16个字
    distractors = randomDistractors(wordPool, D, exclude=allChars)
    allChars.extend(distractors)
    
    // 5. 随机排列到网格
    grid = shuffle(allChars)
    emptySlots = G*G - len(grid)
    fillWithBlanks(grid, emptySlots)
    
    // 6. 验证至少1个词可在前5次操作中被发现（可玩性保证）
    if not hasDiscoverableWord(grid, targetWords, maxAttempts=5):
        goto step 4  // 重新生成
    
    return {grid, targetWords, config}
```

### 4.2 经济系统

#### 货币定义

| 货币 | 图标 | 用途 | 获取途径 |
|------|------|------|----------|
| **金币** 🪙 | 铜钱 | 购买道具、解锁皮肤 | 对局奖励、签到、成就 |
| **星尘** ✨ | 星光 | 升级段位、解锁词库 | 对局经验、连胜加成 |
| **体力** ❤️ | 心 | 每局消耗1点 | 自动恢复、购买、看广告 |
| **钻石** 💎 | 宝石 | 购买体力包、限定皮肤 | 内购、成就奖励 |

#### 体力系统

```
体力上限: 5点（初始） → 随等级提升（每10级+1，上限15）
恢复速度: 1点/10分钟（满体力停止恢复）
每日免费补充: 每日签到+3点，分享+1点
观看广告: 每次+1点，每日上限5次
钻石购买: 5钻石=1点，无上限
```

#### 金币获取公式

```
金币 = floor(总分 × 0.15) + 连胜加成

连胜加成:
  连胜2-3局: +20%
  连胜4-6局: +50%
  连胜7+局: +100%
```

#### 星尘（经验）公式

```
星尘 = 命中词数 × 50 + floor(速度分/10)

升级所需星尘: level × 150
```

4. **败局分享**: 超时界面提供「这局太难了，谁来试试？」分享按钮，带本局词展示。

### 7.3 状态机

```
游戏状态:
  IDLE        — 主界面空闲
  LOADING     — 加载资源/生成关卡
  PLAYING     — 对局进行中
  PAUSED      — 暂停
  JUDGING     — 判定提交的词（短暂）
  EXPLODING   — 命中特效播放中（0.5-1秒）
  TIMEOUT     — 倒计时结束
  RESULT      — 结算展示
  AD_WATCHING — 观看激励广告中

状态转换:
  IDLE → LOADING         : 用户点击「开始」且体力≥1
  LOADING → PLAYING      : 关卡生成完毕
  PLAYING → PAUSED       : 用户点击暂停
  PAUSED → PLAYING       : 用户点击继续
  PLAYING → JUDGING      : 用户提交4字组合
  JUDGING → EXPLODING    : 判定命中
  JUDGING → PLAYING      : 判定未命中，卡片回弹
  EXPLODING → PLAYING    : 特效播放完毕，未全命中
  EXPLODING → RESULT     : 特效播放完毕，全部命中
  PLAYING → TIMEOUT      : 倒计时到0
  TIMEOUT → RESULT       : 自动跳转结算
  RESULT → IDLE          : 点击返回首页
  RESULT → LOADING       : 点击再来一局
  RESULT → AD_WATCHING   : 点击双倍奖励
  AD_WATCHING → RESULT   : 广告播放完毕，更新奖励
  ANY_STATE → IDLE       : 返回手势/Home键
```
