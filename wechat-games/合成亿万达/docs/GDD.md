## 1. 核心概念

### 1.1 一句话描述

> 拖拽合并钞票堆，从"小目标"一路合成到"宇宙首富"，离线也能躺着赚钱的放置合成游戏。

### 1.2 目标用户画像

| 维度 | 描述 |
|------|------|
| **年龄** | 18-45岁 |
| **性别** | 男女均等（偏男性60%） |
| **游戏偏好** | 喜欢放置类（Idle）、合成类（Merge）、2048类休闲游戏 |
| **核心爽点** | "暴富"主题、"数字增长"快感、碎片时间可玩 |
| **典型场景** | 通勤、午休、睡前刷手机5-15分钟 |
| **付费习惯** | 轻度付费（看广告为主），偶尔小额内购 |

### 1.3 核心循环（30秒内完成）

```
┌──────────────────────────────────────────────┐
│                                              │
│   ① 拖拽合井  ──→  ② 获得更高级货币/金币    │
│       ↑                              ↓       │
│   ⑤ 离线收益累积              ③ 消耗金币购买道具 │
│       ↑                              ↓       │
│   ④ 挂机自动产出低级货币（在线+离线）         │
│                                              │
└──────────────────────────────────────────────┘
```

**30秒体验路径：**
> 打开游戏 → 看到满屏钞票/金币堆（挂机收益弹出）→ 拖拽两个"小目标"合并 → 弹出"亿万达" + 金币雨动画 → 爽感达成

**获得 → 消费闭环：**

| 获得什么 | 消费什么 |
|----------|----------|
| 挂机产出低级货币 | 购买"自动合成"加速券 |
| 合并得高级货币+金币 | 购买皮肤/主题/道具 |
| 看广告得钻石+加速 | 升级离线收益倍率 |
| 成就奖励 | 解锁新合成槽位 |

## 2. 玩法机制

### 2.1 操作方式

| 操作 | 说明 |
|------|------|
| **拖拽** | 长按一个物品 → 拖动到同等级物品上 → 松手合并（主操作） |
| **点击** | 点击物品查看信息；点击空槽位选择放置；点击道具使用 |
| **长按** | 长按物品1秒进入拖拽模式（防误触） |

### 2.2 核心规则（3条）

1. **同等级合并**：两个相同等级的货币物品拖拽到一起，合成为高1级的物品，并获得 `(新等级 × 基础金币系数)` 的金币奖励。
2. **挂机自动产出**：无论在线/离线，系统每隔 N 秒在随机空槽位生成1个最低等级"钢镚"（有概率暴击产出"小目标"）。
3. **槽位即上限**：棋盘有固定槽位数（初始9格，可扩展至25格），槽位满则停止产出，需手动合并腾出空间。

### 2.4 得分系统

玩家的「总身价」是核心得分指标，由三部分组成：

```
总身价 = 棋盘上所有物品面值之和 + 历史累计金币 × 0.01 + 成就加成
```

- **棋盘面值**：当前棋盘上所有物品按面值累加
- **历史金币转换**：每100金币折合1点身价
- **成就加成**：完成成就获得的身价倍率（如×1.1, ×1.5）

金币是独立消耗货币（购买道具），不直接等同于身价。

## 4. 数值系统

### 4.1 得分公式

```
总身价 = Σ(棋盘物品面值) + floor(累计金币 / 100) × 成就倍率
```

示例：棋盘上有1个"亿万达"(100亿) + 3个"小目标"(3亿) + 累计100万金币 + 成就倍率1.5
→ 身价 = (100亿+3亿) + 100万/100 × 1.5 = 103亿 + 15000 ≈ 103亿

### 4.2 挂机产出公式

**在线挂机：**

```
产出间隔 = max(0.5, 5 - 0.3 × floor(玩家等级/5)) 秒
每次产出数量 = 1 + floor(玩家等级/10)
产出等级分布 = 按权重随机（见3.2表）
```

**离线收益（≤8小时）：**

```
离线收益系数 = min(1.0, 离线小时数/8) × 基础倍率
基础倍率 = 1.0（默认）+ 0.5（看广告翻倍）+ 升级加成

离线总产出 = 在线每分钟产出 × 离线分钟数 × 离线收益系数
```

**离线收益上限：** 最多累计8小时产出。

### 4.3 合成时间

```
手动合成 = 即时（拖拽完成即合并）
挂机自动合成 = 当棋盘满时，每 interval 秒自动尝试合并一对
interval = max(0.5, 3 - 0.2 × floor(玩家等级/5))
```

### 7.2 交互流程图（文字描述）

```
启动游戏
    │
    ├── 首次启动 → 新手引导(3步)
    │      1. "这是你的棋盘，钢镚会自动产出"
    │      2. "拖拽两个钢镚合并成百元钞" (强制引导)
    │      3. "看！你赚到了第一笔金币！"
    │      → 进入主界面
    │
    └── 非首次 → 判断离线时长
            │
            ├── 离线≥5分钟 → 弹出离线收益结算
            │       ├── 看广告 → 收益×2 → 进入主界面
            │       └── 跳过 → 收益×1 → 进入主界面
            │
            └── 离线<5分钟 → 直接进入主界面

主界面循环：
    棋盘自动产出(每N秒) → 槽位有空格 → 生成物品
    玩家拖拽合并 → 播放合并动画 → 奖励金币 → 更新身价
    宝箱出现(每5分钟) → 玩家点击 → 选择开启方式
    体力/时间到了 → 自然等待 or 看广告加速
```

### 7.3 状态机

```
                    ┌──────────┐
                    │  LOADING │ (资源加载)
                    └────┬─────┘
                         │ 加载完成
                         ▼
              ┌─────────────────────┐
              │   TUTORIAL          │ (首次游戏)
              │   新手引导3步        │
              └──────┬──────────────┘
                     │ 引导完成
                     ▼
              ┌─────────────────────┐
         ┌───→│   OFFLINE_REWARD    │ (离线奖励弹窗)
         │    └──────┬──────────────┘
         │           │ 领取/关闭
         │           ▼
         │    ┌─────────────────────┐
         │    │   IDLE              │◄──────────────┐
         │    │   挂机产出+等待操作   │               │
         │    └──┬───┬───┬────┬────┘               │
         │       │   │   │    │                    │
         │       │   │   │    └─ 宝箱出现 ──→  POPUP_CHEST
         │       │   │   │                        │
         │       │   │   └─ 点击道具 ──→  POPUP_SHOP/ITEM
         │       │   │                            │
         │       │   └─ 点击底部导航 ──→  SHOP / LEADERBOARD
         │       │        / ACHIEVEMENT / SETTINGS │
         │       │                                │
         │       └─ 拖拽合并 ──→  MERGING ──→ 播放动画 ──→ IDLE
         │                                        │
         └─── 切后台超过5分钟 ──→  OFFLINE_REWARD ─┘

状态转换条件：
- LOADING → TUTORIAL: isFirstLaunch == true
- LOADING → OFFLINE_REWARD: isFirstLaunch == false && offlineTime >= 300s
- LOADING → IDLE: isFirstLaunch == false && offlineTime < 300s
- IDLE → MERGING: 拖拽同等级物品到相邻格
- MERGING → IDLE: 合并动画播放完毕(约0.5秒)
- IDLE → POPUP_CHEST: 宝箱计时器到期
- IDLE → POPUP_SHOP: 点击道具/商店按钮
- IDLE → OFFLINE_REWARD: 游戏切后台时间≥300秒
```

### B. 风险与应对

| 风险 | 应对 |
|------|------|
| 微信审核驳回（"暴富"主题敏感） | 弱化真实货币暗示，强调"虚拟身价"概念 |
| 广告填充率低 | 增加道具直购钻石路径，减少对广告的依赖 |
| 数值膨胀过快 | 预留Lv16~Lv20扩展空间，保持长线目标感 |
| 用户流失（中后期无聊） | 定期运营活动（限时双倍合成、新主题、赛季排行） |
